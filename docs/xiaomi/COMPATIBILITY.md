## 公开预览版与电视已部署版本的区别

已部署版本是 v1.5.6-mi1，并通过独立适配组件连接原生设置和 HDMI。
本公开版 v1.5.6-mi2 将等价路由集成进桌面，移除了个人应用与壁纸初始化，增加可复用安装 / 恢复脚本。
公开版完成编译、签名校验、输入映射回归；**尚未在另一台用户设备上完整跑过公开安装脚本及全部真机交互**。
上述真机记录用于说明适配依据，不能冒充公开 APK 在所有设备上的验收结果。

## HDMI ID 不是通用端口编号

| 卡片 | TvInputInfo ID | 小米整数 input |
| --- | --- | --- |
| HDMI 1 | com.mediatek.tvinput/.hdmi.HDMIInputService/HW5 | 23 |
| HDMI 2 | com.mediatek.tvinput/.hdmi.HDMIInputService/HW6 | 24 |
| HDMI 3 | com.mediatek.tvinput/.hdmi.HDMIInputService/HW7 | 25 |

HW8 虽由框架报告，但该机型原生菜单没有第四个 HDMI 入口，因此只对这个型号隐藏。
深蓝色根据 INPUT_STATE_CONNECTED 绘制；线缆、电源、分辨率或 HDCP 等问题仍可能导致无画面。

## 不作保证的情况

- 其他 Xiaomi / Redmi 型号、不同固件、Google TV 机型。
- 小米所有升级渠道是否被关闭、未来固件是否重设 Home、恢复出厂后的保留情况。
- 电视开机广告、原生屏保推荐和第三方视频软件内的广告。
- 输入设备的 HDR、CEC、HDCP、特定刷新率与音频格式；只记录已测项目。

不要因为同为“小米”或同为“Android 9”就套用其他型号的系统精简清单。
